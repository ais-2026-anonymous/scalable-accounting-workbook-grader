# ACC3000 instructor grader

In the same browser profile that issued the assignment, enter the recorded checksum and select the submitted .xlsm files. Python grades against each student's protected source data. The results show the attention check separately and can be downloaded as CSV.

Issuance records are local to this browser profile. To grade from another profile, restore the private backup on the [workbook generator](https://ais-2026-anonymous.github.io/scalable-accounting-workbook-generator/) first. The checksum identifies the issued assignment version.
